# HVAC & Home Services Landing Page

A conversion-focused landing page built for HVAC, plumbing, roofing, rental, and other home service businesses.  
The goal is to help businesses turn website visitors into leads through a clean, fast, and mobile-friendly interface.


## 🚀 Features

- Clean and responsive landing page design  
- Service showcase section (HVAC, plumbing, roofing, rentals, etc.)  
- Lead capture form (name, phone, message)  
- Backend API built with Node.js + Express  
- Stores leads in a JSON file  
- Mobile-first layout optimized for conversions  


## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- Node.js  
- Express.js  


## 📂 Project Structure

/public
index.html
style.css
script.js

server.js
leads.json


## ⚙️ How It Works

1. User visits the landing page  
2. User fills the contact form  
3. Form data is sent to the backend API (`/submit`)  
4. Data is stored in `leads.json`  
5. Business receives lead information for follow-up  


## 🎯 Purpose

This project is built to demonstrate practical web development skills focused on real-world business use cases, especially for small service-based businesses that need more leads and customer conversions.
